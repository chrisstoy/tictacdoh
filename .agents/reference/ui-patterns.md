# UI Patterns

- **Styling:** NativeWind 4 (Tailwind 3 `className` on RN components); content glob `./src/**/*.{js,jsx,ts,tsx}`; `darkMode: 'class'` but app is light-only (`userInterfaceStyle: 'light'`). Custom plugin in `nativewind.plugin.js`.
- **Palette** (`tailwind.config.js`, semantic names): `background` #fdde97 (soft yellow), `border` #632f16 (dark line art), `text` #2b262c, `highlight` #c46f24 (active player). Splash/theme color matches `background`.
- **Layout:** the root view fills the height and is centered with `maxWidth` = window height × 0.62 (`frameMaxWidth` in `src/services/frameWidth.ts`, applied through `useFrameMaxWidth` in `src/services/useFrameMaxWidth.ts`). The hook applies no cap until after mount: the static export prerenders with a 0×0 window, and a prerendered `max-width:0px` is never repaired on hydration (React does not patch style attributes), so the first paint collapsed until a resize. Phones are unaffected; iPad and desktop get a tall column that fills the screen instead of a small phone-sized box at the top. The web document uses `viewport-fit=cover` (`src/app/+html.tsx`). `SafeAreaView` in the root layout is the only inset, including inside the Capacitor shell. On iOS and Android the status bar is `#fdde97` with dark icons, and only when `isNativeShell()` is true.
- **Images:** each `assets/*.png` is wrapped by a component in `src/components/images/` (`XImage`, `OImage`, `MascotImage`, ...). Add a wrapper rather than importing PNGs inline. `SplashScreenImage` is `assets/splash-screen.png` with `resizeMode="contain"`.
- **Buttons/text:** `PushButton`, `JiggleButton`, `Toggle`, `OutlineText`, `TextWithBackground` are the shared primitives. `OutlineText` strokes by `outlineWidth` pixels on web and native. Animations (`src/animations/`) use react-native-reanimated 4 (`FadeIn`/`FadeOut` between screens).
- **Title screen:** cold start, before setup. The splash is contained on `#fdde97`. Play sits under it and pulses (`startPlayIdle`) unless `useReducedMotion()` is on; the press plays the `push` sound. Play is `assets/play.png` via `PlayImage` (`testID` `play-image`), the `start-game.png` pill with PLAY drawn in Arial Black. It matches Start Game's pill and colors, but the lettering is a close approximation, not the original font; replace the PNG if matching art exists. The mascot is a featureless base image (`assets/mascot/base.png`, `MascotImage`) with its eyes, brows, and mouth as separate cut-out PNGs (`MascotFace`) animated independently by `facePoseAt`; the face layer is hidden from accessibility. See `architecture.md`.
- **Options screen:** Auto-Play, Sound, and Music toggles, then the Return button (`accessibilityLabel` Return), then the app version in small muted text (`testID` `app-version`, from `useAppVersion`). It is how to tell which build is installed, e.g. `v1.0 (61)` after a TestFlight upload.
- **Setup online entry:** when `isOnlineSetupAvailable()` is true (Worker URL set), setup shows **Online Create** / **Online Join** (`OnlineSetupPanel`) above Start Game on web/PWA and native. Create uses the current rounds-in-match value; Join shows a room-code field (6 alphanumeric, trim+uppercase). Unset Worker URL keeps the local-only setup layout.
- **Online lobby:** `OnlineLobbyScreen` shows the room code, waiting copy, **Share** (Capacitor Share on native; Web Share / clipboard on web) and **Cancel** (leaves the session). When `hostConnected && guestConnected`, the app advances to play.
- **Online play:** `PlayGameScreen` reuses the local board/score UI. Online taps send `move` only on my seat’s turn; Next Round / Play Again / Quit use accessibility labels `Next round` / `Play again` / `Quit game` and call the online session APIs. `OpponentDisconnectedOverlay` (`testID` `opponent-disconnected-overlay`) covers the board with “Opponent disconnected…” and an optional reclaim countdown.
- **Fonts:** Komigo3D, loaded via expo-font from `assets/fonts/`. The layout renders before it loads, so text briefly shows the fallback font and then swaps (see `architecture.md` Hydration).
- **Debug:** `DebugViewData.tsx` for inspecting state.
- **watchOS:** the wrist app does not use NativeWind. It is SwiftUI in `ios/App/TicTacDohWatch`, on the same `#fdde97` background, with X and O from `MarkX`/`MarkO` assets. Cold start is `SplashView` (`SplashScreen` asset scaled to fit — never cropped — + **Play** with `WatchActionChrome`). Default `WordmarkText` uses `WatchLayout.wordmarkSize` (20 on 40mm-class, 23 otherwise); explicit sizes (Quit, splash Play, compact result lines) stay as written. The play board uses taupe tiles (empty cells lighter than filled) with dark `#632f16` grid lines; winning tiles use a brighter orange fill. Shared `WatchLayout.cornerRadius` (8) on tiles, board, pills, and action buttons. Active-turn score pill pulses via `TimelineView`. Setup roles/rounds, **Start Game**, **Next Round**, and **New Match** use `WordmarkText` + `WatchActionChrome`. Round/match result banners use `WordmarkText` (winner mark + `WINS` / stacked `WINS`/`THE MATCH`, or draw wording). Round counter stays quiet system text; Quit stays available on end screens for bail-out. See `architecture.md`.
